
# Linux System Report Generator

A lightweight command-line utility designed to automate the extraction of fundamental system metrics on a Linux machine. When executed, the script collects the data and formats it into a readable text document.

## Features Included in the Report
- System Hostname
- Linux Kernel Version
- Disk Space Utilization
- Memory (RAM) Usage
- Top Running Processes (sorted by CPU consumption)

## Prerequisites
Ensure you are operating within a Linux or Unix-like environment with standard utilities (`bash`, `uname`, `df`, `free`, `ps`) installed.
